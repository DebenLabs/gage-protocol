# Security reporting

Please report vulnerabilities privately. Do not post exploit details, credentials or private user information in issues or pull requests.

Auditors should use the private reporting channel agreed for their engagement. Other researchers should read the current [Gage bug bounty policy](https://docs.gage.cash/protocol/bug-bounty) and use the [private report form](https://gage.cash/bugbounty/report). The policy defines current eligibility, scope and submission conditions. If the form is unavailable, contact [@gagedotcash](https://x.com/gagedotcash) to arrange private reporting.

Include the repository commit, affected component, impact, relevant environment and enough evidence for the maintainers to assess the report. Keep testing isolated and do not use discovered credentials or touch real user assets or private data.

This source release and its automated checks are not an audit certification. The initial review scope is in [docs/AUDIT_SCOPE.md](docs/AUDIT_SCOPE.md).
